# RTX 5090 Benchmark Results

These results were measured on a Vast.ai 1x RTX 5090 instance:

- GPU: NVIDIA GeForce RTX 5090, compute capability 12.0
- Driver: 580.126.09
- CUDA: 13.0
- Python: 3.12.3
- MAX/Modular: 26.4.0.dev2026051206
- PyTorch: 2.11.0+cu130
- `ptxas`: `/usr/local/cuda/bin/ptxas`

The first run on a fresh virtual environment was used to warm MAX's interpreter
op cache. The recorded warm-cache GPU smoke run passed:

```text
15 passed, 2 warnings in 5.30s
```

`examples/train_linear.py` converged:

```text
step=000 loss=9.000000 weight=0.000000 bias=0.000000
step=005 loss=0.006047 weight=1.999360 bias=0.922240
step=010 loss=0.000037 weight=2.000000 bias=0.993953
step=015 loss=0.000000 weight=2.000000 bias=0.999530
step=020 loss=0.000000 weight=2.000000 bias=0.999963
```

PyTorch CUDA float32 matmul precision used the benchmark default:

```text
torch_float32_matmul_precision: high
torch.backends.cuda.matmul.allow_tf32: True
torch.backends.cudnn.allow_tf32: True
```

## Small CUDA Workload

```bash
RUN_SYNC=0 RUN_TESTS=1 RUN_EXAMPLE=1 RUN_BENCHMARK=1 \
BATCH_SIZE=128 INPUT_DIM=64 HIDDEN_DIM=128 OUTPUT_DIM=16 \
WARMUP_STEPS=2 STEPS=5 REPEATS=2 TORCH_COMPILE_MODE=max-autotune \
scripts/gpu_smoke.sh
```

```text

---------------------------  ------  ---------  ---------  -------  ---------  ------------  ----------
torch_eager                  ok      0.000000   0.546      1832.63  234577.0   0.878090      0.722726
torch_compile[max-autotune]  ok      1.499954   0.447      2238.03  286467.9   0.878090      0.722925
max_eager                    ok      0.000000   57.319     17.45    2233.1     0.878090      0.722725

```

The small workload was run after cache warmup, so the `max_compile` compile time
is a warm-cache number.

## Larger CUDA Workload

```bash
MODULAR_NVPTX_COMPILER_PATH=/usr/local/cuda/bin/ptxas \
uv run --no-sync python benchmarks/pytorch_compile.py \
    --device cuda --batch-size 1024 --input-dim 256 --hidden-dim 512 \
    --output-dim 64 --warmup-steps 5 --steps 20 --repeats 3 \
    --torch-compile-mode max-autotune
```

```text
engine                       status  compile_s  median_ms  steps/s  samples/s  initial_loss  final_loss
---------------------------  ------  ---------  ---------  -------  ---------  ------------  ----------
torch_eager                  ok      0.000000   0.642      1557.35  1594727.6  0.981283      0.665560
torch_compile[max-autotune]  ok      11.145166  0.524      1908.16  1953952.6  0.981283      0.665603
max_eager                    ok      0.000000   59.021     16.94    17349.8    0.981284      0.665561
max_compile                  ok      44.666601  0.339      2950.37  3021181.0  0.981284      0.665604
```

PyTorch `max-autotune` printed several Triton candidate failures because some
candidate kernels exceeded the RTX 5090 resource limit:

```text
OutOfMemoryError: out of resource: triton_mm Required: 262144 Hardware limit:101376
```

The benchmark still completed with `ok` status and selected valid kernels.

The larger workload was measured after the small workload but with a fresh
MAX-compiled train-step shape, so the `max_compile` compile time includes graph
compile/loading for this workload while interpreter op caches were already warm.
